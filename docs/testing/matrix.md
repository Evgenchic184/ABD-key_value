# Матрица тестов KVDB

Матрица описывает автоматические проверки локальной базы, HTTP-доступа,
репликации и шардирования. Одна строка соответствует одной тестовой функции pytest.
Всего 85 функций, которые с учётом параметризации дают **119 отдельных
проверок**. Проверки хранения используют собственные фикстуры и временные
каталоги. Интерактивный сценарий демонстрации запускается отдельно.

Команды установки зависимостей, запуска тестов и формирования HTML coverage
приведены в [README](../../README.md#тестирование).

## Границы проверок

- Проверяется общий экземпляр движка в одном процессе; границы поддержки
  описаны в [ограничениях реализации](../implementation.md#ограничения) и
  [границах синхронизации](../concurrency.md#сохранение-закрытие-и-границы-синхронизации).
- HTTP-обработчики проверяются через TestClient, обмен с ведущим в T72 —
  через MockTransport. T61 запускает uvicorn в отдельном процессе и обращается
  к нему по TCP. T84 запускает два настоящих узла и проверяет шардирование по
  сети, но без реплик и без Docker. Эти проверки не заменяют запуск
  многопроцессного кластера.
- Есть небольшой стресс-тест корректности; нет измерений производительности и длительного стресс-теста.
- Аварийное завершение процесса проверяется; реальное отключение питания и сбои носителя не моделируются.
- Ошибки дисковых операций проверяются через mock; это не проверка конкретной файловой системы.
- Высокое покрытие строк и ветвей не доказывает отсутствие гонок.

## Демонстрационный сценарий

[Сценарий Docker](../replication.md#сценарий-отказов) запускается через
веб-интерфейс и не использует pytest. Он показывает сетевую синхронизацию,
управляемую паузу и отставание, остановки и перезапуски узлов, восстановление
по WAL и снимку, чтение с резервного узла и итоговую сходимость данных.
Результаты запросов выводятся в интерфейсе и сохраняются в JSONL-журнале.
Этот сценарий не входит в число автоматических проверок таблиц.
Сценарий шардирования из [документа о шардировании](../sharding.md#сценарий-демонстрации)
запускается через `compose.sharding.yaml` и также не входит в таблицы.
