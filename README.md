# KVDB

KVDB — учебная key-value база данных на Python со строковыми ключами и
байтовыми значениями. В основе проекта — локальный движок со снимками данных и
журналом операций (WAL). Доступ к базе планируется через Python API, CLI и HTTP.

## Текущее состояние

Определены интерфейсы базы и хранения. Рабочий движок и сервер ещё не готовы.
